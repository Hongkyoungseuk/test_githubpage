# test_githubpage 실험용
### github사용법
1. Settings > pages 에 들어간다
2. Build and deployment > Source > Deploy from a branch 선택
3. Build and deployment > Branch 에 해당 디랙토리 설정 후 save
4. 상위로 돌아가 Actions에서 빌드 되는지 확인
